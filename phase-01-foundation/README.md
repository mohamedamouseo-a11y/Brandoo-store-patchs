# Phase 01 — Foundation

Goal: establish the Brando custom WordPress theme before visual homepage work.

## Included
- Custom theme: `brando`
- Arabic/RTL-ready structure
- WooCommerce support
- Responsive base tokens/layout
- Header + footer foundation
- Main/RTL CSS and JS asset loading
- Safe placeholder front page for Phase 02

## Apply target
Copy `files/wp-content/themes/brando/` into the WordPress project at `wp-content/themes/brando/`, then activate the theme and ensure WooCommerce is installed and active.

Do not build the final homepage in this phase. Phase 02 will implement the approved mockup.
